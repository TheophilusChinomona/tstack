# tstack — Codex Adaptation

tstack provides AI engineering workflow skills. This directory contains the adapter for OpenAI Codex.

## Files

- `AGENTS.md` — Codex equivalent of Claude Code instructions
- `agents/` — Codex-specific agent role definitions
- `config.toml` — Codex configuration overrides

## Install

```bash
cp -R .codex/* ~/.codex/
```
